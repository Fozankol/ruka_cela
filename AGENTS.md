# РУКА ЦЕЛА: браузерная игра для Sharrowkin Jam

Концепт: docs/GDD.md. План: docs/PLAN.md. Задачи для Sharrowkin: docs/TASKS.md.

Стек: Vite, JavaScript (ES-модули), Three.js. Бэкенда нет.
Запуск: npm run dev. Сборка: npm run build, результат в dist/ с относительными путями. Баланс: npm run sim.

Структура:
- src/sim/: логика без DOM и Three.js, чтобы её запускал симулятор;
- src/content/: тексты, карты, цены, весь текст на русском;
- src/render/: всё, что рисует Three.js;
- src/ui/: интерфейс;
- src/audio/: звук.

К игроку обращаемся на «ты» и без указания рода: «Ты здесь 2 часа», а не «Ты провёл здесь 2 часа».
Графика и звук создаются кодом. Чужие файлы берём только с разрешающей лицензией и записываем в CREDITS.md.

Нельзя:
- отправлять данные игрока куда-либо, просить камеру или микрофон;
- использовать настоящих политиков, флаги и названия стран в сюжете;
- делать резкие громкие скримеры и частое полноэкранное мерцание;
- класть большие файлы в репозиторий, игра должна загружаться за несколько секунд.
