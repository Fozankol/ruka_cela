# План джема

Сдача: **воскресенье, 1 ноября, 20:00 МСК**. Опоздание означает работу вне конкурса.

## Что важно из правил

- Сдаём ссылку на игру и видео на 30 секунд. Менять работу можно до конца джема.
- Игра открывается по ссылке, без установки.
- Чужие картинки, звук и шрифты только с разрешением.
- Жюри оценивает три вещи: весело, по теме, как выглядит.

## Кто что делает

Правила джема требуют, чтобы основную работу делал Sharrowkin. Организаторы в Telegram разрешили продолжать в других нейросетях, пока в приложении отключены модели. Автор принял решение писать код в Claude Code на свой риск.

| Кто | Что |
|---|---|
| **Claude Code** | Движок, масштабы, баланс, сюжет, проверка в браузере |
| **Sharrowkin** | Отдельные задачи в своих файлах: docs/TASKS.md |
| **Автор** | Играет, решает, записывает видео, сдаёт работу, хранит скриншот разрешения организаторов |

## Порядок работы

| Срок (МСК) | Контрольная точка |
|---|---|
| Сб, 16:30 | Все этапы и финал соединены в одну цепочку, автор играет в полную версию |
| Сб, вечер | Правки по игре автора, публикация и сдача черновика |
| Вс 12:00 | Баланс по живой игре, звук событий |
| Вс 17:00 | Заморозка, запись видео |
| Вс 18:30 | Финальная сдача, полтора часа в запасе |

## Риски

| Риск | Что делаем |
|---|---|
| Организаторы снимут работу за код не в Sharrowkin | Автор хранит скриншот разрешения, часть задач уходит в Sharrowkin, при сдаче решение за автором |
| Жюри не дойдёт до финала | Инстинкт на ×8 проходит войну примерно за 8 минут |
| Слабые ноутбуки жюри | Автоснижение качества, на стратегических картах нет размытия |
| Финал срабатывает от случайного дрожания | Допуск 12 пикселей, быстрая повторная попытка |
| Звук заблокирован браузером | Запуск после первого клика |

## Публикация

Remote у репозитория нет, поэтому основной вариант: `npm run build` и папка `dist/` в Netlify Drop руками автора. Запасной: GitHub Pages. Перед сдачей проверяем ссылку в чистом окне браузера и на другом устройстве.

## Видео на 30 секунд

Концовку не показываем.

| Секунды | Кадр |
|---|---|
| 0–6 | Спальня, рука, укус, вспышка, «Рука цела.» |
| 6–12 | Рой выходит из щели, дом гаснет |
| 12–22 | Непрерывный отъезд: дом, улица, село, город, планета, огни гаснут |
| 22–28 | Белый кокон, камера отъезжает, восемь звёзд открываются |
| 28–30 | Название игры на чёрном |
