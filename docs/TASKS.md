# Задачи для Sharrowkin

Основной код пишет Claude Code. Здесь только отдельные задачи: каждая меняет свои файлы и не трогает остальные, чтобы работа не конфликтовала.

Как запускать: открыть эту папку в Sharrowkin, каждую задачу вставлять в новый чат (/new).

## S1. Города мира

```text
Прочитай @docs/GDD.md. Создай только файл src/content/cities.js: экспорт массива из 150 крупнейших городов мира, разнесённых по всем континентам, включая Ташкент.
Поля каждого города: id, name (по-русски), lat, lon, population. Округли население до тысяч. Другие файлы не меняй.
Проверка: node -e "import('./src/content/cities.js').then(m=>console.log(m.CITIES.length))" печатает 150.
```

## S2. Звук (не запускать, сделано в Claude Code)

```text
Прочитай @docs/GDD.md, раздел «Как устроен страх». Создай только файлы в папке src/audio/, главный файл: src/audio/GameAudio.js. Игра подключит его сама через src/core/sound.js.
Сделай модуль на Web Audio без внешних файлов. Экспорт: класс GameAudio с методами unlock(), setMaster(v), setDread(v от 0 до 1), play(name, {pan, volume}), radioStatic(on).
Имена звуков: step, scuttle, bite, slipper, lightOn, lightOff, wireSnap, cocoon, hatch, heartbeat, uiClick, radioBlip, alarm, explosion, windowOpen.
Постоянный фон: низкий гул, который меняется от setDread. Резких пиков громкости быть не должно.
Проверка: сделай страницу tools/audio-test.html с кнопкой на каждый звук.
```

## S3. Пауки поверх интерфейса

```text
Прочитай @docs/GDD.md, раздел «Как устроен страх». Создай только файл src/ui/crawlers.js.
Экспорт: класс Crawlers. Он создаёт прозрачный canvas поверх страницы с pointer-events: none, рисует процедурных пауков с анимированными лапами, которые перебегают по экрану и иногда по курсору, а в углах растит паутину. Методы: setInfection(v от 0 до 1), update(dt), destroy().
При 0 ничего не видно, при 1 экран заметно заражён, но кнопки читаются. Пауки появляются редко и не мешают клику.
Проверка: сделай страницу tools/crawlers-test.html с ползунком заражения.
```

## S4. Обложка и экран загрузки

```text
Прочитай @docs/GDD.md. Создай только файл src/ui/title.js и стили к нему в src/ui/title.css.
Экспорт: функция showTitle({onStart}), показывающая чёрный экран с названием «РУКА ЦЕЛА», строкой «Паук против человека», кнопкой «Начать», предупреждением о пауках и мерцании, переключателем «Меньше мерцания». Для названия подбери шрифт с кириллицей под лицензией OFL и запиши его в CREDITS.md.
Стиль: минимальный, страшный, никаких картинок.
Проверка: сделай страницу tools/title-test.html.
```

## S5. Тестовый прогон

```text
Запусти игру (npm run dev), пройди первые 15 минут и составь docs/playtest.md: где непонятно, где скучно, что сломано, с точными шагами воспроизведения. Код не меняй.
```

## S6. Глобус

Запускать после S1: глобус берёт города из её файла.

```text
Прочитай @docs/GDD.md, разделы «Масштабы» и «Внешний вид». Создай только файлы src/render/Globe.js, src/content/land.js и страницу tools/globe-test.html. Другие файлы не меняй.
Сделай на Three.js класс Globe(scene): ночная Земля с настоящими материками (Natural Earth 110m через пакет world-atlas, public domain), атмосферой, облаками и огнями городов из src/content/cities.js. Город по lat и lon переводится в точку сферы радиуса 1.
Методы: setCityLight(id, v от 0 до 1), setSilk(v от 0 до 1), addThread(fromId, toId), update(dt), dispose().
setCityLight гасит огни плавно. addThread рисует светящуюся серебряную дугу между городами. setSilk(1) превращает планету в матовый белый кокон с волокнами, а атмосфера из голубой становится серой и болезненно-белой.
Цель: 60 FPS на встроенной графике, один проход шейдера без тяжёлых эффектов.
Проверка: на tools/globe-test.html есть ползунок шёлка, кнопка «погасить случайный город» и кнопка «добавить нить».
```

## S7. Финал

```text
Прочитай @docs/GDD.md, раздел «Финал». Создай только файлы src/ui/finale.js, src/ui/finale.css и страницу tools/finale-test.html. Другие файлы не меняй.
Экспорт: функция showFinale({ stats, onEnd }). stats содержит minutes, clicks, food. Это полноэкранный слой поверх игры, чёрный, без Three.js.
Сделай шаги 2, 4, 5, 6, 7 раздела: текст «Осталась одна особь. На планете её нет.», паутина затягивает экран, курсор вязнет и отстаёт (свой курсор на canvas), статистика с настоящим местным временем («Сейчас 03:12. Почему ты не спишь?»), запись Лены с эффектом радиопомех и 20 секунд «НЕ ДВИГАЙСЯ».
Во время отсчёта слушай мышь, клавиатуру и касания. Допуск дрожания мыши 12 пикселей суммарно. Кнопка «+1 000 000 шёлка» считается движением.
Концовки: шевельнулся: чёрный экран и «Население Земли: 0», кнопка повторить шаг 7. Выдержал: долгая пауза и белые буквы «РУКА ЦЕЛА.». onEnd вызывается с 'lost' или 'won'.
К игроку обращайся на «ты» и без указания рода.
Проверка: на tools/finale-test.html обе концовки срабатывают, неподвижная мышь не сбрасывает отсчёт.
```

## S8. Радио

```text
Прочитай @docs/GDD.md, разделы «Главные идеи» и «Сюжет», и файл src/content/story/town.js, таблицу LINES. Создай только файл src/content/story/radio.js. Другие файлы не меняй.
Экспорт: объект RADIO с ключами house, street, village, town, planet. В каждом массив из 6 реплик вида ['Кто', 'Текст']. Реплики короткие, до 90 символов.
История: Лена, девочка из первого дома, выжила, потому что мать крикнула ей не шевелиться. От этапа к этапу она взрослеет и ведёт ночной эфир. Первые реплики этапа бытовые и смешные, последние страшные и личные. На этапе planet часть реплик обращена прямо к игроку.
Никаких настоящих политиков, стран и брендов. Без указания рода для игрока.
Проверка: node -e "import('./src/content/story/radio.js').then(m=>console.log(Object.keys(m.RADIO)))" печатает пять ключей.
```

## S10. События войны

```text
Прочитай @docs/GDD.md и файл src/sim/war.js, метод chooseCard. Создай только файл src/content/war/events.js. Другие файлы не меняй.
Экспорт: массив EVENTS из 30 событий вида { title, text, options: [{ label, effect }, { label, effect }] }.
effect содержит любые из полей biomass, tension, dawn, armies, числа со знаком. biomass от -300 до +600, tension от -8 до +8, dawn от -10 до +10, armies от -2 до +3.
Рой захватывает мир. В событиях люди сопротивляются, а игрок решает за рой: сжечь или сохранить, ударить или затаиться. Лена появляется в каждом третьем событии.
Текст короткий: title до 30 символов, text до 140, label до 50. Без настоящих стран, политиков и брендов. Игрока называй на «ты» без указания рода.
Порядок идёт от бытовых событий к страшным.
Проверка: node -e "import('./src/content/war/events.js').then(m=>console.log(m.EVENTS.length))" печатает 30.
```
