# Задачи для Sharrowkin

Основной код пишет Claude Code. Здесь только отдельные задачи: каждая меняет свои файлы и не трогает остальные, чтобы работа не конфликтовала.

Как запускать: открыть эту папку в Sharrowkin, каждую задачу вставлять в новый чат (/new).

## S1. Города мира

```text
Прочитай @docs/GDD.md. Создай только файл src/content/cities.js: экспорт массива из 150 крупнейших городов мира, разнесённых по всем континентам, включая Ташкент.
Поля каждого города: id, name (по-русски), lat, lon, population. Округли население до тысяч. Другие файлы не меняй.
Проверка: node -e "import('./src/content/cities.js').then(m=>console.log(m.CITIES.length))" печатает 150.
```

## S2. Звук

```text
Прочитай @docs/GDD.md, раздел «Как устроен страх». Создай только файлы в папке src/audio/, главный файл: src/audio/GameAudio.js. Игра подключит его сама через src/core/sound.js.
Сделай модуль на Web Audio без внешних файлов. Экспорт: класс GameAudio с методами unlock(), setMaster(v), setDread(v от 0 до 1), play(name, {pan, volume}), radioStatic(on).
Имена звуков: step, scuttle, bite, slipper, lightOn, lightOff, wireSnap, cocoon, hatch, heartbeat, uiClick, radioBlip, alarm, explosion, windowOpen.
Постоянный фон: низкий гул, который меняется от setDread. Резких пиков громкости быть не должно.
Проверка: сделай страницу tools/audio-test.html с кнопкой на каждый звук.
```

## S3. Пауки поверх интерфейса

```text
Прочитай @docs/GDD.md, раздел «Как устроен страх». Создай только файл src/ui/crawlers.js.
Экспорт: класс Crawlers. Он создаёт прозрачный canvas поверх страницы с pointer-events: none, рисует процедурных пауков с анимированными лапами, которые перебегают по экрану и иногда по курсору, а в углах растит паутину. Методы: setInfection(v от 0 до 1), update(dt), destroy().
При 0 ничего не видно, при 1 экран заметно заражён, но кнопки читаются. Пауки появляются редко и не мешают клику.
Проверка: сделай страницу tools/crawlers-test.html с ползунком заражения.
```

## S4. Обложка и экран загрузки

```text
Прочитай @docs/GDD.md. Создай только файл src/ui/title.js и стили к нему в src/ui/title.css.
Экспорт: функция showTitle({onStart}), показывающая чёрный экран с названием «РУКА ЦЕЛА», строкой «Паук против человека», кнопкой «Начать», предупреждением о пауках и мерцании, переключателем «Меньше мерцания». Для названия подбери шрифт с кириллицей под лицензией OFL и запиши его в CREDITS.md.
Стиль: минимальный, страшный, никаких картинок.
Проверка: сделай страницу tools/title-test.html.
```

## S5. Тестовый прогон

```text
Запусти игру (npm run dev), пройди первые 15 минут и составь docs/playtest.md: где непонятно, где скучно, что сломано, с точными шагами воспроизведения. Код не меняй.
```
