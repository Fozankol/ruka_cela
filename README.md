# Рука цела

Хоррор-стратегия для Sharrowkin Jam: один паук под кроватью захватывает дом, улицу, село, город и всю планету.

## Запуск

```bash
npm install
npm run dev
```

Игра откроется на http://localhost:5183.

## Сборка

```bash
npm run build
```

Готовая игра лежит в `dist/`, пути относительные. Баланс войны считает `npm run sim`.

Каждый пуш в `main` сам выкладывает игру на GitHub Pages: см. `.github/workflows/pages.yml`. В настройках репозитория в разделе Pages источник должен быть GitHub Actions.

## Управление

| Этап | Что делать |
|---|---|
| Дом | Клик по вкусняшке посылает рабочего. При тревоге снимай рабочих кликом по красным меткам. |
| Улица | Зажми мышь и тяни нить от паутины. Клик по столбу отправляет Грызуна, клик по двери начинает захват. Вдова кусает того, по кому кликнешь. |
| Село | Нити ведут рабочих к еде. Гнёзда ставятся на паутине, бойцы защищают их, восемь бойцов берут набат. |
| Город и Мир | Клик по легиону, затем по региону: идти или атаковать. Shift добавляет к выбору, двойной клик берёт всех в регионе, правая кнопка снимает выбор. Пробел ставит паузу, клавиши 1–4 меняют скорость. |
| Звук | Кнопка с нотой в правом верхнем углу открывает громкость: общая, музыка, звуки. Клавиша M выключает музыку. |

На обложке можно начать сначала, сразу перейти к захвату мира или выбрать этап.

## Правила проекта

В игре нет настоящих стран, флагов и политиков. Данные игрока никуда не отправляются, камера и микрофон не используются, сохранение лежит только в браузере.
